# OR Learning Lab — Каталог випускних ІТ-проєктів

Семантичний адаптивний сайт українською мовою: 30 проєктів, пошук, фільтри, паспорти, копіювання та друк.

## Файли
- `index.html` — HTML5-структура сторінки.
- `styles.css` — адаптивний дизайн і стилі друку.
- `app.js` — пошук, фільтрація та діалог паспортів.
- `projects.json` — дані про 30 проєктів; можна редагувати окремо від коду.
- `logo.svg`, `favicon.svg` — логотип і фавікон.

## Як запустити локально

У папці із сайтом виконайте:

```bash
python -m http.server 8000
```

Потім відкрийте `http://localhost:8000` у браузері.

**Важливо:** якщо відкрити `index.html` подвійним клацанням як `file://`, браузер може заблокувати `fetch('projects.json')`. Використовуйте локальний сервер або GitHub Pages.

## Публікація на GitHub Pages

Завантажте файли в корінь репозиторію, увімкніть **Settings → Pages → Deploy from a branch**, виберіть `main` та `/ (root)`.

## Семантика і доступність

Сторінка використовує `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `form`, `label`, `dialog`, `h1–h3`, `ol`, `ul`. Є skip-link, видимий фокус, підписи до форм, клавіатурна навігація, закриття діалогу клавішею Escape, `aria-live` для кількості результатів та підтримка `prefers-reduced-motion`.

## Редагування каталогу

Додавайте або змінюйте записи в `projects.json`. Кожен об'єкт має поля `id`, `name`, `subtitle`, `category`, `level`, `team`, `problem`, `audience`, `features`, `mvp`, `tech`, `growth`, `test`.

Паспорти — навчальні пропозиції, а не затверджені теми. Технології можна змінювати відповідно до підготовки учнів.
